# PRAIA'S GRILL — Plataforma Profissional de Cardápio Digital e Gestão Gastronômica

Sistema completo para o restaurante Praia's Grill (São José de Ribamar - MA), incluindo:
- **Ambiente 1 (Cliente)**: Cardápio digital com identificação rápida por Nome e WhatsApp, personalização avançada de pratos, acompanhamentos, carrinho inteligente, opções de delivery e retirada no local.
- **Ambiente 2 (Gestão /gestao)**: Painel operacional para controle de pedidos em tempo real, status, comandas, cardápio e base de clientes.
- **Ambiente 3 (Master /master)**: Painel administrativo estratégico com controle de estoque, fichas técnicas, custos, simulação de precificação e margens, construtor de combos e relatórios completos.

## Acesso
- Acesse `/` para o cardápio e pedidos do cliente.
- Acesse `/gestao` para o painel de atendimento do restaurante.
- Acesse `/master` para o painel master do proprietário da plataforma.
